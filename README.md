
# 🎮 Hangman Game - CodeAlpha Internship

## 📌 Project Description
Hangman is a simple text-based word guessing game developed using Python as part of the CodeAlpha Python Programming Internship.

The player has to guess a randomly selected hidden word by entering one letter at a time.

## ✨ Features
- Random word selection
- 5 predefined words
- Maximum 6 incorrect guesses
- One-letter input validation
- Prevents repeated guesses
- Winning and losing conditions
- Simple console-based interface

## 🛠️ Technologies Used
- Python
- Random Module
- While Loop
- If-Else Statements
- Strings
- Lists

## ▶️ How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

```bash
python main.py
```
